About the Project

How We Built It

This project is a fully functional Minesweeper game built from the ground up in Java, developed as our final project for the Higher Degree in Multi-platform Application Development (DAM).

The application features an interactive graphical interface where players can reveal cells, place flags, and trigger the classic mine-explosion sequence. Under the hood, every game session is persisted to a MySQL relational database through a JDBC connection layer, enabling score tracking, leaderboard management, and player history.

The project is organized using a standardized Maven structure, which automates the build process, seamlessly handles external dependencies like the MySQL connector, and ensures a clean, reproducible lifecycle for the entire application.

Tech Stack

  • ☕Java 21 — Core language
  • 🗄MySQL — Relational database
  • 🔌JDBC — Database connectivity
  • 📦Maven — Build tool & dependency management
  • 🛠VS Code / NetBeans — IDE
