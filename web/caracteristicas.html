Características

01
💣

Generación de Minas

Algoritmo de distribución aleatoria con semilla configurable. El tablero se recalcula en cada nueva partida garantizando variedad.

Core Logic
02
🗄️

Conexión a Base de Datos

Registro de partidas, puntuaciones y jugadores en MySQL mediante JDBC. Historial persistente entre sesiones.

MySQL · JDBC
03
🖥️

Interfaz Gráfica

GUI desarrollada con JavaFX: tablero interactivo, banderas, temporizador en tiempo real y efectos visuales de explosión.

JavaFX
04
👤

Gestión de Usuarios

Sistema de registro basico de jugadores y tabla de clasificación global almacenada en la base de datos relacional.

Auth · Ranking
05
⚙️

Niveles de Dificultad

Tres modos de juego: Facil (9×9), MEdio (16×16) y Dificil (16×30) con densidades de minas diferenciadas.

Game Design
06
📦

Estructura Maven

Gestión automatizada del ciclo de vida del proyecto y resolución de dependencias externas para un entorno de desarrollo estandarizado.

Build Tool
